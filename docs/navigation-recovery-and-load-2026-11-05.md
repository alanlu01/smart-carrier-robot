# 2026-11-05 導航恢復與診斷減負

基準版本 `559f0a5`。依上午10:41–11:05實車紀錄修正；不調整定位門檻、車速、INA設定、yaw_ratio或0.000389，不更新OS/ROS/Hailo。

## 修改

1. **診斷減負**：移除navigation_health對高頻bond與TF的即時訂閱。`/navigation/pipeline_health`仍每秒發布六個服務的精簡健康摘要，ready判定仍為active且最近3秒有回應；單次服務等待仍0.75秒。服務逾時計數、耗時等移至`/navigation/diagnostics`，每5秒發布一次，BEST_EFFORT depth=1。原始bond與TF仍保存在原有rosbag，供離線完整分析。
2. **AMCL重置後恢復**：導航服務恢復但AMCL仍無姿態時，不再無限等待姿態作為恢復的先決條件。需確認新鮮本機scan/odom/四輪回授、實體停穩、無取還禁止移動／橫移租約、導航ready與全域初始化服務就緒，持續2秒後才重建全域定位。不使用舊位置直接放行。要求來源時間更新的AMCL姿態，15秒未取得則安全轉人工，不重複初始化；後續仍走既有全域幾何與健康樣本驗證。自動定位動作停用時不自行啟動。
3. **訂單可靠恢復**：可辨識動作確認／結果通訊逾時及生命週期服務失效，保留同一訂單重試，而非立即回報任務失敗。明確無路徑、碰撞、進度不足仍不當作暫時通訊故障。沿用持久化最多2次重試額度，新設90秒整體恢復期限；重新派發前須具備新鮮scan/odom/TF、四輪停穩證據與連續1秒資料就緒。雲端取消與返航接管仍先處理。
4. **旋轉末段**：最後45°限速倍率0.65，最後12°為0.45；依角速度預留0.4秒停止尾段、提前1–8°煞停。若已停穩但不足角度仍大於3°，經原安全與停穩檢查後只低速補足剩餘角度，限速0.25、提前1°停下，仍受同一時間及續轉次數限制。超轉超過3°不再標示精準完成，不反向回正，改在停穩後驗證定位。這些角度皆為odom量，實車物理角度仍需實測。
5. **狀態文字**：增加「等待導航服務恢復」「等待AMCL姿態恢復」「等待地圖／TF更新」「等待底盤回授恢復」等摘要，Delivery沿用圖示與簡短文字；機器狀態碼保留。
